# Раскладка вдоль коридора

## Задача

Общая раскладка (`EggField.layout`) кладёт объекты по всей площадке планеты. На планете с коридором это значит — за стенами, куда не дойти. Нужна вторая раскладка, и выбор между ними без ручного флага.

## Выбор режима

Признак коридора — узел зон в модели планеты (`model:FindFirstChild(ZoneConfig.Nodes.Folder)`). Есть узел → `corridorSpots`, нет → общая раскладка. Флаг в конфиге дублировал бы то, что уже лежит в месте, и расходился бы с ним.

## corridorSpots

```lua
local function corridorSpots(surface): { Vector2 }
	local length = ZoneField.length()          -- длина коридора из той же геометрии, что зоны
	local rng = Random.new(surface.id)          -- детерминизм: один и тот же id — одна раскладка
	local spots = table.create(surface.chests)
	for index = 1, surface.chests do
		-- равные промежутки: центр каждого из N отрезков, от −length/2 до +length/2
		local along = length * ((index - 0.5) / surface.chests - 0.5)
		-- поперёк — случайно, но не у стены: 30% полуширины
		table.insert(spots, Vector2.new(along, rng:NextNumber(-1, 1) * ZoneConfig.Width * 0.3))
	end
	return spots
end
```

- Ось «вдоль» — ось коридора в осях планеты; переводится в мир той же матрицей, что и зоны.
- Сид — id поверхности/планеты: сервер и любой клиентский предпросмотр дают одну картину, и раскладка не пересобирается при повторном входе.
- Количество — из конфига поверхности, не константа в модуле.

## Смежное правило: возврат из обработчика удара

Функция удара по объекту с HP возвращает **идентификатор сломанного** и `0`, если задетое устояло. Возврат цели при `left > 0` заставляет вызывающего начислять за каждое касание — экономический баг, невидимый в визуале. Комментарий у функции обязан говорить, что именно возвращается: «зона СЛОМАННОГО, 0 — не попало или устояло».

## Проверка

- сундуков ровно `surface.chests`, все внутри `[-length/2, length/2]` по длине и внутри `±Width×0.3` по ширине;
- два вызова с одним id дают одинаковые точки, разные id — разные;
- планета без узла зон идёт общей раскладкой.

## Чеклист

- [ ] Режим выбирается по узлу в месте, не по флагу
- [ ] Сид детерминированный, из id поверхности
- [ ] Промежутки равные, отступ от стен в долях ширины из конфига
- [ ] Обработчик удара возвращает `0`, пока цель не сломана

## Антипаттерны

- `Random.new()` без сида в раскладке — объекты прыгают при повторном входе
- Ручной список координат сундуков на планету
- Возврат цели из `Strike` независимо от того, сломана ли она

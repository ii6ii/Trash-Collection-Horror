# Образец пропа из груды мешей

## Когда

Художник принёс пак (груда мешей разного роста и наклона), из которого код клонирует образец в каждую ячейку сетки. Нужен один Studio-инструмент, который собирает образец идемпотентно, и правила посадки, по которым его раскладывает игра.

## Инструмент сборки (`tools/build-<биом>-cell.luau`)

Живёт на диске вне `src` — в место не синкается, запускается из студии. Порядок:

1. Найти пак в `ServerStorage.Assets.<Pack>`, запасно — в `Workspace` (свежепринесённый пак не перекладывать руками). Нет — `error(...)`, не молчать.
2. Взять **все** `BasePart` пака как есть: положение, размеры, наклоны. Не выбирать «красивые» куски — разный рост груды и есть вид, ради которого её рисовали.
3. У каждой детали снести детей кроме `SurfaceAppearance` (на нём весь вид, без него серый пластик). Выставить `Anchored`, `CanCollide/CanQuery/CanTouch = false`, `CastShadow = false`.
4. Посчитать габарит по **мировым** осям (см. ниже), поставить `WorldPivot`.
5. Снести старую папку образцов, собрать заново — инструмент идемпотентен.
6. Вернуть строкой размеры и во что образец вырастет в ячейке — числа печатать, а не смотреть глазами.

## Габарит по мировым осям

`Model:GetBoundingBox()` меряет в осях пивота — у наклонённых кусков габарит врёт. Половина мирового габарита повёрнутой коробки — `|R| · halfSize`:

```lua
local least, most = Vector3.one * math.huge, Vector3.one * -math.huge
for _, part in model:GetChildren() do
	local cf, half = part.CFrame, part.Size * 0.5
	local r, u, b = cf.RightVector, cf.UpVector, cf.LookVector
	local reach = Vector3.new(
		math.abs(r.X) * half.X + math.abs(u.X) * half.Y + math.abs(b.X) * half.Z,
		math.abs(r.Y) * half.X + math.abs(u.Y) * half.Y + math.abs(b.Y) * half.Z,
		math.abs(r.Z) * half.X + math.abs(u.Z) * half.Y + math.abs(b.Z) * half.Z
	)
	least = least:Min(part.Position - reach)
	most = most:Max(part.Position + reach)
end
```

Тот же расчёт нужен и в клиентском коде раскладки, если он меряет образец сам.

## Пивот

- `PrimaryPart` **не ставить**: с ним пивот берётся от детали, а `WorldPivot` движок молча игнорирует — груда садится в ячейку боком.
- `WorldPivot` = середина подножия, без поворота: `CFrame.new((minX+maxX)/2, minY, (minZ+maxZ)/2)`. По нему клетка садится на пол, вокруг него разворачивается, им же масштабируется — `ScaleTo` тянет от пивота, подножие остаётся на месте.

## Посадка в ячейку

| Режим | Когда | Как |
| :--- | :--- | :--- |
| По ширине (по умолчанию) | образец выше, чем шире | масштаб = `Step / max(size.X, size.Z)` |
| По росту (`FitByWall[band]`) | груда шире, чем выше: по ширине встала бы «по колено» | масштаб = `Wall × доля / size.Y`; соседние ячейки заходят друг на друга, поле читается сплошным |

Доля стены — вкус геймдизайна (полный рост закрывает обзор на цель). Разброс размера/разворота/наклона считать от **номера клетки**, не от `Random` без сида: зона пересобирается при каждом возврате, случайность перетасовала бы коридор на глазах.

## Папка, а не модель

Образцы лежат папкой `Assets.ZoneProps.<Name>`; код берёт любой из детей по номеру клетки. Второй пак от художника — положить рядом, код не меняется. Имя папки читается из конфига (`CellConfig.Nodes.Cell[band]`), и наличие узла в месте закрывается тестом — промах деградирует в пустой коридор без ошибки.

## Чеклист

- [ ] Пак берётся целиком, ничего не перекрашивается
- [ ] Габарит по мировым осям, не `GetBoundingBox`
- [ ] Пивот в подножии, `PrimaryPart` пуст
- [ ] Режим посадки (рост/ширина) записан в конфиг по банде
- [ ] Инструмент идемпотентен и печатает размеры
- [ ] Тест на наличие папки образца в месте

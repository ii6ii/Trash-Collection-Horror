# Процедурные замахи на Motor6D

## Когда

Нужен цикл ударов инструментом с несколькими стилями (рубящий, режущий, подбив, левая рука), без клипов на каждый, поверх штатной ходьбы.

## Каркас

- **Две позы на стиль** — `Wound` (занёс) и `Swing` (ударил), градусы по костям. Между ними косинус: `wave(cycle) = cos(2π(cycle + 0.5)) × 0.5 + 0.5`. У непрерывного цикла начало и конец сходятся — стыка нет.
- **Часы свободные**: `cycle += dt / period`, никогда не обнуляются — ни на касании, ни на смене цели. Перезапуск с нуля и есть рывок при частой рубке. Вход/выход из рубки делает **вес**, не перезапуск.
- **Отставание костей**: у каждой кости своя фаза `wave(cycle − Lag × Depth[limb])`; `Depth` 0 у корпуса, 1 у кисти, порядок общий (кисть раньше плеча нельзя), размах `Lag` свой у стиля. Вся мягкость — из отставания, не из амплитуды.
- **Отдача** — пружина на плече рабочей руки, добавляется к позе (`turn += Recoil × shock`), ничего не перезапускает.

## Композиция поворотов

```lua
-- Доворот вбок ПОВЕРХ выноса руки вперёд. Один CFrame.Angles(X, Y, Z) уводит Y внутрь выноса,
-- и вынесенная рука крутится вокруг своей длины вместо хода вбок.
return CFrame.Angles(0, rad(turn.Y), 0) * CFrame.Angles(rad(turn.X), 0, rad(turn.Z))
```

На этом держатся режущие стили — вся их дуга по Y.

## Запись в сустав

```lua
motor.Transform = played:Lerp(if arm[limb] then turn else played * turn, weight)
```

- `played = motor.Transform` — то, что положил аниматор в этом кадре.
- Кости **рабочей руки** заменяют клип (замах и ходьба спорят, побеждает замах).
- Корпус, голова, вторая рука — доворот **поверх** клипа: подмена целиком выключила бы ходьбу.
- **Только `RunService.Stepped`**: из `Heartbeat`, `RenderStepped`, `BindToRenderStep` запись до отрисовки не доживает — аниматор кладёт поверх свою позу, рука не двигается, молча.
- Класс сустава — `AnimationConstraint` или `Motor6D` в зависимости от версии аватара; слот `Transform` у обоих.

## Имена костей и R6

Кость → список имён сустава: `RightUpperArm = { "RightShoulder", "Right Shoulder" }`. Второе имя — R6: нет локтя, кисти, пояса, замах идёт одним плечом — честный минимум, не поломка. Кисть/хват: `{ "RightHand", "Right Arm" }`, `RightGripAttachment`; нет attachment — берём саму кисть. Нет рабочего плеча вовсе — `new` возвращает `nil`, владелец живёт без позы.

## Связки стилей

- `Combo[style] = { s1, s2, s3 }` — удары идут по кругу; нет связки — один стиль.
- Стиль меняется **в момент касания**: рука отработала своё, переход уходит в возврат к замаху.
- Перетекание: `mix` от 0 до 1 за `Mix` секунд (меньше такта, иначе не успеет); поза = `key(from):Lerp(key(style), mix)`. Фаза для `from` считается по **его** `Lag` — общая даст рывок временем, не позой.
- Хват тоже перетекает: `gripFrom = текущая посадка на момент смены` (не хват прошлого стиля — оборванный переход вернул бы позапрошлый одним кадром).
- Смена рабочей руки: риг пересобирается, если `rig.side ~= style.Hand`; старая подписка `Destroy()`.
- Неизвестный номер стиля/инструмента → первый стиль, не пустой замах.

## Чеклист

- [ ] Часы не обнуляются, вход/выход весом
- [ ] Порядок `Y × (X, Z)` в композиции
- [ ] Запись в `Stepped`, владелец только оставляет состояние
- [ ] Рабочая рука заменяет, остальное поверх
- [ ] Отдача добавляется, не перезапускает
- [ ] Переход по `mix` с фазой прошлого стиля по его `Lag`
- [ ] R6-имена и фолбэки на отсутствие attachment/плеча

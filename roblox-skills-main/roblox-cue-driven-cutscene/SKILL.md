# Катсцена по cue с гарантией возврата

## Расписание

Все моменты сцены — одна таблица `Cue` в конфиге, секунды от первого кадра: `Brake, Hatch, Jump, Land, Rise, Stand, Return, Done`. Кадровый шаг сравнивает часы с cue и переключает флаги `_braked/_jumped/_landed` один раз. Отсчёт свой, с кадра, в котором приехал пакет — не от серверного времени.

Спек на инварианты: `Jump < Land < Stand <= Return < Done`; отрезок возврата камеры не меньше времени пружины (обрезанная сцена добирает остаток скачком).

## Сервер и клиент — одно число

Сервер держит ноги/состояние ровно столько, сколько идёт сцена: `SessionConfig.Landing.Show` обязан равняться `Cue.Stand`. Тест на равенство обязателен — иначе игрок либо стоит и не может идти, либо идёт, пока его ещё вытряхивают. Запреты кнопок (`EvacuateLock`) — не меньше `Cue.Done`.

## Гарантия возврата

Сцена отбирает ноги (`PlatformStand`), HUD и камеру. Кадровый шаг могут снять со стороны (`UnbindFromRenderStep` соседней сценой с тем же именем, смена персонажа), и сам он не заведётся — игрок остаётся лежать без выхода. Поэтому:

```lua
function Show._guard(self)
	local token = self._token
	task.delay(CUE.Done + Config.Guard, function()
		if token == self._token and self._running then self:Stop() end
	end)
end

function Show._step(self, dt)
	local ok, err = pcall(function() self:_frame(dt) end)
	if not ok then warn(...); self:Stop() end
end
```

- `_token` растёт в каждом `Stop`: сторож прошлой сцены не снимет новую.
- Имя `BindToRenderStep` — своё на сцену (`"PlanetArrival"`), одноимённая привязка соседа сняла бы шаг у обеих. Приоритет — до рига камеры, иначе цели отстают на кадр.
- `Stop` идемпотентен, чистит `Trove`, возвращает `CameraType`, и **после** этого поправляет кадр (`Dropoff.restoreView`).
- Чужому персонажу (сцена соседа) ноги и HUD не трогаем — это делает его клиент; прячем только тело.

## Общий модуль Dropoff

Одинаковые движения двух сцен (высадка на планету, возврат на базу) — в одном модуле; числа у сцен свои.

| Функция | Что делает |
| :--- | :--- |
| `floorAt(at, character, humanoid, probe, reach)` | луч вниз от точки с исключением самого персонажа; возвращает кадр стойки (`HipHeight + половина корня`) и точку пола для пыли |
| `awaitPeer(player, spot)` | ждёт реплику соседа у присланной точки (`PEER_REACH`, `PEER_WAIT`); нет — сцену не играть |
| `arc(fall, from, land, axis, span, elapsed)` | баллистика с рывком вверх `Pop`; ускорение подбирается так, что касание ровно на `span`; вбок `u^Throw` (рывок, потом торможение); кувырок садится ногами вниз с `Upright` |
| `homeView(root, home)` | снимает zoom/высоту взгляда с **живой** штатной камеры (настройка игрока), запасные числа из конфига |
| `followShot(base, view, pitch)` | кадр за спиной с отступом **по взгляду**, каким его продолжит штатная камера |
| `restoreView(view)` | поворот входа, если сцена оборвана до передачи кадра |

Тест дуги: `arc(..., span, span)` приходит в `land` с точностью `1e-3`, первый кусок дуги выше точки старта.

## Тело в сцене

Управление отобрано — корень пишется CFrame без оглядки на физику, скорости обнуляются каждый кадр. До люка тело просто держится на площадке (спрятанное, оно не в кадре; отпущенное — сползает физикой).

- [ ] Серверная длительность == `Cue.Stand`, тест на равенство
- [ ] `_guard` + `pcall` в шаге + токен
- [ ] Своё имя привязки, приоритет до рига
- [ ] `Stop` идемпотентен и возвращает камеру после `Trove`

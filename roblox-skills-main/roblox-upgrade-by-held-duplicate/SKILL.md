# Прокачка расходом дубликата из рук

Сервер решает, кто донор, и списывает его атомарно. Клиент только показывает, что будет.

## Контракт

| Решение | Дефолт | Почему |
| :--- | :--- | :--- |
| Кто донор | Только экипированный Tool | Игрок сам выбирает, кого слить. Автовыбор «слабейшего из рюкзака» сжигает не того |
| Что такое дубликат | Тот же вид и тот же вариант (мутация, скин) | Уровень донора в идентичность не входит |
| Сколько даёт донор | `min(cap, level + max(1, donorLevel))` | Перенос, а не создание уровней; `max(1, …)` страхует битый профиль |
| Перелёт за потолок | Сгорает | Осознанный sink лишних прокачанных дублей. Закрепить тестом и в ГДД |
| Что не качается | Потолок, пустой слот, не тот тип (яйцо, fused) | Каждый случай — свой статус ответа |

Перенос не ломает экономику «1 дубликат = 1 уровень»: уровни донора уже оплачены дублями и
переезжают целиком. Размножить уровень нельзя, пока донор расходуется полностью, а вид и вариант
обязаны совпадать.

## Сервер

1. Найти слот и проверить досягаемость и владельца (как у остальных действий со стендом).
2. Донор: `character:FindFirstChildOfClass("Tool")` → id записи из атрибута → запись в пуле.
   Рюкзак не смотреть. Tool без записи в пуле — призрак, отказ.
3. Снять снимок донора ДО списания: им возвращается предмет, если уровень не запишется.
4. Закрыть накопленный доход по СТАРОЙ ставке. Не закрылся — выйти, ничего не тронув.
5. Списать донора одной записью профиля (`Update`), где наличие проверяется ВНУТРИ колбэка.
   Пока летел пакет, игрок мог поставить этого же зверя на стенд.
6. Поднять уровень и записать слот. Запись упала — вернуть уровень и выдать донора обратно из снимка.
7. Ответить статусом на любой исход: `Ok`, `MaxLevel`, `NotEnough`, `NotUpgradable`, `TooFar`, `Failed`.

Функция списания пула обычно умеет «забрать и выдать взамен». Дайте ей `give = nil` («только
забрать»), а не пишите второй путь записи.

## Промпт у стенда

- На клавише один контекстный промпт: пустые руки — Pick Up, чужой зверь — Swap, валидный дубликат
  ниже потолка — Upgrade. На потолке дубликат снова получает Swap.
- Приоритет задаётся в общем предикате действий, по которому сервер проверяет запрос, а не порядком
  промптов на клиенте: `Swap = … and not upgradable`. Иначе на одной клавише два действия, и выбирает
  движок.
- Нажатие Upgrade шлёт тот же запрос, что и кнопка в окне: ответ, тост и VFX у них общие.

## Клиент

- Предпросмотр «Lvl A → Lvl B» и «доход → доход» считается ТОЙ ЖЕ общей функцией `upgradedLevel`,
  что и на сервере. Без донора в руках показывать базовый случай: донор первого уровня.
- Руки отслеживать через `Character.ChildAdded` и `ChildRemoved`. Смена Tool — это уход и приход,
  поэтому перерисовка раз на кадр через `task.defer`.
- Пока ждём ответ, кнопка серая. Нажатие по серой объясняет причину тостом, а не молчит.

## Тесты

- `isDuplicate`: тот же вид с любым уровнем подходит, другая мутация, редкость или яйцо — нет.
- `donor`: берётся только id из рук, призрак и nil не проходят.
- `upgradedLevel`: `5 + 10 = 15`, перелёт режется потолком, донор с уровнем 0 даёт +1.
- Сервис: дубликат из рюкзака без рук даёт `NotEnough`; после прокачки донор исчез из пула и из рук,
  соседние дубли целы; мутация стенда сохранилась.
- Упавшая запись уровня возвращает донора в пул.
- Таблица промптов: дубликат ниже потолка — только Upgrade, на потолке — Swap, другая мутация — Swap.

## Чеклист

- [ ] Донор только из экипированного Tool и сверен с пулом
- [ ] Доход закрыт до смены уровня
- [ ] Списание атомарное, наличие проверено внутри записи
- [ ] Откат уровня возвращает донора из снимка
- [ ] Каждая ветка отказа отвечает статусом

## Антипаттерны

- Брать донора из рюкзака автоматически: игрок теряет зверя, которого не выбирал.
- Проверять наличие донора до записи и списывать отдельно: окно для дюпа через стенд.
- Сначала поднять уровень, потом списывать: сбой записи даёт бесплатную прокачку.
- Включать уровень донора в проверку «дубликат»: прокачанный дубль перестаёт подходить.
- Дублировать формулу перехода в UI: табличка обещает один уровень, сервер выдаёт другой.

# Толкание объекта и зоны доставки

## Контакт держится взглядом, а не расстоянием

Толчок продолжается, пока направление взгляда совпадает с направлением на объект:
`look · toObject >= FacingDotMin`. Проверка только по расстоянию даёт эффект «объект ходит
за игроком»: развернулся — а он всё ещё в радиусе и продолжает ехать.

Точка приложения считается **впереди игрока** (`position + look * offset`), и тоже только пока
условие взгляда держится. Без этого при развороте объект рывком перелетает на новую сторону.

Разворот, уход за дистанцию, прерывание — все три завершают толчок одним и тем же путём.

## Зона проверяется по XZ

Попадание объекта в зону (доставки, парковки, цели) считается **без оси Y**:

```lua
-- высота объекта не обязана совпадать с высотой зоны
local function isPointInZoneXZ(point, zone)
	local local_ = zone.CFrame:PointToObjectSpace(point)
	local half = zone.Size * 0.5
	return math.abs(local_.X) <= half.X and math.abs(local_.Z) <= half.Z
end
```

Объём с высотой кажется honestly точнее и молча не срабатывает: толкаемый объект едет на своей
высоте, зона нарисована по земле, пересечения нет никогда. Ось Y добавляется только если
вертикаль действительно часть условия (этаж, яма).

## Авторолл

Наклонная поверхность — отдельная зона: объект в ней едет к цели сам, без удержания игроком.
Право на движение проверяется до шага, а не внутри: заблокированный объект на склоне
не катится и не фиксируется.

## Шаг вместо физики в тестах

Полная физика Roblox в тестах даёт флаки: шаг зависит от частоты кадров и от состояния движка.
Движение оформляется функцией шага, которую тест дёргает сам (`StepForTests(dt)`), а рантайм
вызывает из своего цикла. Тем же способом подставляются стартовые позиции объектов
(`PlaceForTests`) и права (`SetUnlockOverrideForTests`).

Это не «тестовый хак»: детерминированный шаг — единственный способ проверить, что объект
приходит в зону за предсказуемое время.

## Пересчёт на каждом выходе

Любой путь завершения толчка обязан пересчитать состояние и промпты — включая тихие:
игрок вышел из игры, объект удалён, действие прервано чужой системой. Пропущенный пересчёт
оставляет промпт выключенным навсегда; баг воспроизводится редко и не ищется.
Правила для самих промптов — `roblox-competing-proximity-prompts`.

## Чеклист

- [ ] Толчок гейтится взглядом, а не только дистанцией
- [ ] Точка приложения впереди игрока и пересчитывается каждый шаг
- [ ] Попадание в зону — по XZ, если вертикаль не часть условия
- [ ] Право на движение проверяется до шага
- [ ] Движение вынесено в функцию шага, тест дёргает её сам
- [ ] Все пути выхода, включая тихие, пересчитывают состояние

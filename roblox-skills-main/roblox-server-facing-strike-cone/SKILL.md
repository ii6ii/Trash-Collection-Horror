# Конус удара по серверному взгляду

## Принцип

Клиент присылает только **факт такта** (пакет без направления и без целей). Всё остальное сервер берёт сам:

| Величина | Откуда |
| :--- | :--- |
| Позиция | `HumanoidRootPart.Position` реплики персонажа |
| Направление | `root.CFrame.LookVector` — та же реплика, то же доверие, что и к позиции |
| Радиус, сила, инструмент | профиль игрока (`DataManager`), не пакет |
| Что попало | своя сетка клеток (`CellField`) и своё состояние HP в сессии |

Направление от клиента в пакете — подделка одним числом: удар «во все стороны» или за спину. Позиция персонажа и так реплицируется с доверием к клиенту, добавлять к ней второе доверенное поле незачем.

## Конус (`CellField.wedge`)

```lua
-- size: размер зоны, point: игрок в осях зоны, facing: взгляд в осях зоны (XZ),
-- radius: дальность, half: полуугол в градусах
function CellField.wedge(size, point, facing, radius, half)
	local found = CellField.around(size, point, radius) -- круг — дешёвая широкая фаза
	if facing.Magnitude < 1e-3 or half >= 180 then
		return found -- без направления сектор вырождается в круг
	end
	local look, edge, under = facing.Unit, math.cos(math.rad(half)), CellConfig.Step * 0.5
	-- оставить клетки, чей центр в секторе ИЛИ под ногами (стоять внутри несрубленной нельзя)
	...
end
```

Взгляд переводится в оси зоны через `bounds.CFrame:VectorToObjectSpace(look)`, берутся X и Z. Клиентский предсказатель (визуал удара) считает **тот же** `wedge` с теми же числами — разойдутся, клетка приминается у одного и падает у другого.

## Начисление

- Сила/награда начисляется **за слом** (`left <= 0`), не за каждый удар: по целой клетке ударов десятки, и за удар это была бы цена клетки целиком.
- Функция удара по препятствию возвращает зону **сломанного**, иначе `0`. Возврат цели при `left > 0` молча начислял бы за каждое касание.
- Одна запись в профиль на такт, а не по клетке.

## Тесты (обязательны)

- сектор: все найденные клетки либо под ногами, либо `dot(away, look) >= cos(half)`;
- конус уже круга при направлении и равен кругу без него;
- клетка под ногами остаётся, куда бы ни смотрел игрок;
- радиус растёт с уровнем, нулевой ничего не берёт;
- слом даёт начисление, удар без слома — нет.

## Чеклист

- [ ] В пакете такта нет направления и нет списка целей
- [ ] Направление берётся из `LookVector` реплики персонажа
- [ ] Клиентский визуал использует ту же функцию сектора и те же константы
- [ ] Начисление только на сломе, одна запись профиля на такт
- [ ] Половина угла в конфиге с пометкой, если геймдизайн числа не дал

## Антипаттерны

- `direction` / `targets` в пакете от клиента
- Круг вокруг игрока «чтобы было проще» — косит то, что за спиной
- Разные радиусы/углы у сервера и клиента
- Начисление за удар, а не за слом
